CORE

教えの核心

CORE

縁起とは何か

縁起は、物事が単独の原因で起こるのではなく、複数の条件がそろうことで生起し、条件が変われば結果も変わるという見方です。

CORE

戒とは

仏教の倫理実践で、行為を整え、心の混乱を減らすための訓練として位置づけられます。

CORE

業とは何か

業は「運命」や「罰」の意味ではなく、基本的には意図を伴う行為を指します。行為が習慣や結果を形づくるという倫理的・心理的な因果の考え方です。

CORE

空（くう）とは

物事に固定した実体を見いださず、条件関係の中で捉える大乗仏教の重要概念。

CORE

五蘊とは何か

五蘊は、人間の経験を色・受・想・行・識の五つのまとまりとして観察する枠組みです。魂の部品表ではなく、「私」と呼んでいる経験を分解して見るための分析です。

CORE

悟りとは

仏教で悟りは、無知や執着が根本から転換されることとして語られます。

CORE

四諦とは何か

四諦は、苦・集・滅・道という四つの観点から問題を診断する枠組みです。悲観論ではなく、苦には原因があり、原因が弱まれば苦も弱まり、そのための道があるという構造です。

CORE

十二因縁とは何か

十二因縁は、無明から老死までを十二支で示す縁起の代表的な定式です。単純な一方向の時間表ではなく、苦が成立する条件連鎖を読むための枠組みです。

CORE

禅定とは

心を一つの対象に安定させる実践で、八正道の正定とも関係します。

CORE

智慧とは

仏教でいう智慧は、無常・苦・無我や縁起を直接的に理解する力として語られます。

CORE

中道とは何か

中道は「何事もほどほどに」という一般論だけではありません。釈迦の文脈では、感覚的快楽への耽溺と自虐的な苦行という二つの極端を避け、解脱に向かう実践の道を指します。

CORE

八正道とは何か

八正道は、正見・正思惟・正語・正業・正命・正精進・正念・正定からなる実践体系です。八項目を順番にクリアするチェックリストではなく、互いに支え合う訓練と考える方が適切です。

CORE

無我とは何か

無我は「私は存在しない」と宣言する単純な形而上学ではありません。経験を構成するものの中に、完全に支配でき、永続し、これこそ私だと言える固定核を見出しにくいという分析です。

CORE

無常とは何か

無常は「何もかも虚しい」という標語ではありません。条件によって生じたものは変化し続け、同じ状態に固定できないという観察です。

CORE

輪廻とは何か

輪廻は仏教の伝統で重要な位置を占めますが、現代日本では「生まれ変わり」という一語だけで理解されがちです。初期経典では業・渇愛・生存への執着と結びついて語られます。

CORE

涅槃とは何か

涅槃はしばしば「死後の天国」のように誤解されますが、初期仏教では貪り・怒り・無知の火が鎮まることとして説明されます。

PRACTICE

実践

PRACTICE

慈とは

他者の幸福を願う心で、慈悲の「慈」にあたります。

PRACTICE

慈悲とは何か

慈悲は「優しい人になる」だけではありません。苦しむ存在に対して害を減らし、苦の軽減を願い、そのためにどう行動するかを考える態度です。

PRACTICE

正念とは

八正道の一つで、身体・感受・心・法を明晰に観察する実践。

PRACTICE

煩悩とは

欲・怒り・無知など、苦を生みやすい心の傾向を指す総称です。

PRACTICE

悲とは

他者の苦を見て、それが和らぐことを願う心です。

PRACTICE

瞑想とは

止と観、念、禅定など、目的と方法の異なる実践があります。

LIFE

悩みと生活

LIFE

死をどう考えるか

死は仏陀の出家物語でも中心的な問いです。仏教は死を美化せず、避けられない事実として正面から見つめることで、限られた時間の使い方を問い直します。

LIFE

執着とは何か

執着は、好きなものを持つこと自体ではありません。「こうでなければならない」「失ってはいけない」と対象や考えを固定し、変化する現実とのずれに苦しむ状態として見ると理解しやすくなります。

LIFE

人間関係をどう見るか

人間関係の苦しみは、相手そのものだけでなく、期待、解釈、言葉、境界線、過去の記憶など複数の条件から生じます。仏教の見方は「我慢すること」ではなく、条件を観察し害を減らすことです。

LIFE

怒りをどう見るか

仏陀の教えは、怒りを単に悪い感情として押し殺すことを勧めるわけではありません。怒りがどんな条件で生じ、どのように言葉や行為へつながるかを観察します。

LIFE

不安をどう見るか

不安は未来を守ろうとする心の働きでもあります。仏教的な実践では、不安を消すことだけを目標にせず、まだ起きていない未来を何度も現在に持ち込む心の癖を観察します。

LIFE

老いをどう見るか

老いは失敗ではなく、生きることに含まれる変化です。仏教は若さを永続させる幻想ではなく、身体の変化を認めながら、何に価値を置くかを問い直します。
