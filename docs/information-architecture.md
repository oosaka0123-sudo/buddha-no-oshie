# Information Architecture v1

## Core promise
2500年前の問いを、いま自分自身の問いとして読む。

## Primary user journeys
- 初心者: 仏陀とは → 生涯 → 四諦・八正道 → 教え全体
- 悩み起点: 不安/怒り/執着/死 → 関連教義 → 原典/出典
- 学習者: 経典 → 学派 → 歴史 → 用語辞典
- 比較理解: 初期仏教 → 大乗 → 密教 → 日本仏教

## 12 core pages
1. `/` HOME — 世界観と主要導線
2. `/buddha/` 仏陀とは — 歴史的人物としてのゴータマ
3. `/life/` 仏陀の生涯 — 誕生から入滅まで
4. `/teachings/` 仏陀の教え — 教義ハブ
5. `/four-truths-eightfold-path/` 四諦・八正道 — 核心解説
6. `/suffering/` 悩みから読む仏陀 — 現代の課題から逆引き
7. `/scriptures/` 経典を読む — 原典・翻訳・背景
8. `/history/` 仏教2500年の歴史 — 時代軸
9. `/schools/` 仏教の宗派 — 学派軸
10. `/dictionary/` 仏教用語辞典 — 横断参照
11. `/about/` このサイトについて — 目的・編集思想
12. `/sources/` 出典・編集方針 — 信頼性・参考文献

## Shared metadata
各記事に最低限以下を持たせる。
- 時代
- 地域
- 学派
- 根拠資料
- 学術的確度: 定説 / 有力説 / 異説 / 伝承
- 最終レビュー日

## Editorial separation rule
「歴史上の釈迦が説いた可能性が高い内容」「初期経典に確認できる内容」「後世に成立した大乗・密教・日本仏教思想」を同一レベルで混在させない。

## Future expansion
第一完成後、四諦・八正道・縁起・無常・無我・五蘊・涅槃・空・中観・唯識・浄土・禅・密教・怒り・不安・孤独・死・老い・執着等を個別記事化し、100〜300ページ規模へ拡張する。
