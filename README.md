# 仏陀の教え — buddha-no-oshie

2500年前の問いを、いま自分自身の問いとして読む。

## Design Concept

古代 × 静寂 × 人間 × 時間 × 知性

モーションテーマは「呼吸・時間・消滅」。派手さを目的化せず、無常や時間の流れをWeb体験として表現する。

## Quality Target

- Awwwards / CSS Design Awards級の独自性と完成度
- Mobile First
- WCAG 2.2 AA
- LCP ≤ 2.5s / INP ≤ 200ms / CLS ≤ 0.1
- Lighthouse Performance / Accessibility / Best Practices / SEO 90+
- prefers-reduced-motion対応
- JavaScriptなしでも主要コンテンツを理解できる構造

## Editorial Principle

各記事に「時代 / 地域 / 学派 / 根拠資料」を持たせる。歴史上の釈迦の教え、初期経典、大乗・密教・日本仏教の後世の思想を区別し、断定できない内容は学説・伝承として明示する。
